# Logo Pieza Clave 2.0 (propuesta)

La P de Pieza hecha con un dado de herramienta: círculo = dado, hexágono = boca, tuerca naranja = la pieza que encaja. Esquinas del mango biseladas a 45°. Nombre en Archivo extendida Black, en curvas.

Comparativa completa: `comparativa-logo.html` · https://claude.ai/artifact/SZfrpgXwGFZp9GXxC7vKHG

| `logo-horizontal-negativo.svg` | Sobre Acero o fotos oscuras |
