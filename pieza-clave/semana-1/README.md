# Semana 1 en Instagram

Plan completo: `plan-semana-1.html` · https://claude.ai/artifact/CChYSmAC41shTB3d4nobhM

| Carpeta | Qué tiene |
|---|---|
| `posts/` | Las 21 piezas listas para publicar (1080 × 1350 feed, 1080 × 1920 reels e historias). El prefijo dice el día: `lun-`, `mar-`, `mie-`, `jue-`, `vie-`, `sab-`, `dom-`. |
| `referencias-ia/` | Imágenes de referencia para Higgsfield: el gato en 9:16, la foto original y los productos sin fondo. |
| `productos-sin-fondo/` | Recortes PNG con transparencia de 15 productos, para Canva o CapCut. |
| `fotos-recortadas/` | Las fotos enviadas, sin la interfaz del teléfono. |

Las piezas no llevan precio todavía: el precio va en el texto de cada publicación (`$__`) hasta tener la lista de precios.
