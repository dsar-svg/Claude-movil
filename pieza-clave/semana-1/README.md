# Semana 1 en Instagram

Plan completo: `plan-semana-1.html` · https://claude.ai/artifact/CChYSmAC41shTB3d4nobhM

| Carpeta | Qué tiene |
|---|---|
| `posts/` | Las 25 piezas listas para publicar, con el producto real en escena (1080 × 1350 feed, 1080 × 1920 reels e historias). El prefijo dice el día: `lun-`, `mar-`, `mie-`, `jue-`, `vie-`, `sab-`, `dom-`. |
| `referencias-ia/` | Imágenes de referencia para Higgsfield: el gato en 9:16, la foto original y los productos sin fondo. |
| `productos-sin-fondo/` | Recortes PNG con transparencia de 15 productos, para Canva o CapCut. |
| `escenas-ia/` | Las 21 escenas sin texto (GPT Image 2.6 en ElevenLabs, a partir de las fotos reales), para reusar en historias, anuncios o Canva. |
| `fondos-ia/` | Los 6 fondos generados con IA en ElevenLabs (garaje, banco, patio, rueda, taller, obra) para componer productos nuevos. |
| `fotos-recortadas/` | Las fotos enviadas, sin la interfaz del teléfono. |

Las piezas no llevan precio todavía: el precio va en el texto de cada publicación (`$__`) hasta tener la lista de precios.

Las escenas se generaron con IA a partir de la foto real de cada producto; revisa cada una contra el producto antes de publicar. `lun-3-cc-3-pagos-entregas-PLANTILLA.png` lleva datos por confirmar y no se publica así.
